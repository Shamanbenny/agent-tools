name: grill-with-docs
description: A relentless interview to sharpen a plan or design, while keeping persistent structured notes in a configurable notes directory.
---

## Configuration

```text
NOTES_ROOT=~/.agent-notes
```

Run a `grilling` session and use `personal-doc` to keep a durable working note under `NOTES_ROOT`.

Before the first substantive question, select or create the right note in `NOTES_ROOT`.

Update that note as decisions, open questions, glossary terms, durable findings, and next steps become clear. Keep the note curated rather than append-only.
